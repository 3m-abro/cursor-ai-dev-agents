# Cursor AI Development Agents

**Enterprise-grade AI development workflow orchestration with 16 specialized agents for complete software development lifecycle management.**

## 🚀 What This Is

A comprehensive collection of 16 specialized AI agents that work together in Cursor IDE to build complete software projects from idea to deployment. Each agent has been optimized for maximum efficiency with 80% shorter prompts while maintaining full functionality. They coordinate through intelligent workflow automation to deliver production-ready applications with enterprise-grade quality assurance.

## 🚀 Quick Start

### **Installation**
1. **Clone the repository:**
   ```bash
   git clone https://github.com/3m-abro/cursor-ai-dev-agents.git
   cd cursor-ai-dev-agents
   ```

2. **Open in Cursor IDE:**
   ```bash
   cursor .
   ```

### **Basic Usage**
1. **Open Composer Chat** (Cmd/Ctrl + I)
2. **Type**: `@orchestrator Build a social media app with React Native and Node.js`
3. **Watch the intelligent workflow automation!**

### **Advanced Usage**
1. **Select Template**: `@workflow-templates Select template for e-commerce platform`
2. **Monitor Progress**: `@workflow-monitor Show current workflow status`
3. **Quality Check**: `@quality-gates Validate current phase quality`
4. **Analytics**: `@workflow-analytics Generate performance report`

## 🔧 Customization

### **Agent Configuration**
Edit any agent by modifying the corresponding JSON file in `.cursor/agents/`. Each agent has been optimized with 80% shorter prompts while maintaining full functionality. Customize for specific needs, technology stacks, or quality requirements.

### **Workflow Templates**
Create custom workflow templates by modifying `.cursor/agents/workflow-templates.json` or adding new template configurations. 8 pre-configured templates available.

### **Quality Gates**
Adjust quality thresholds and validation criteria in `.cursor/agents/quality-gates.json` to match your organization's standards. 6-phase validation system.

### **Analytics & Reporting**
Configure analytics parameters and reporting formats in `.cursor/agents/workflow-analytics.json` for customized insights and performance tracking.

### **Error Recovery**
Customize error handling strategies in `.cursor/agents/error-recovery.json` for specific error types and recovery patterns.
