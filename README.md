# Cursor AI Development Agents

11 specialized AI agents for complete software development workflows in Cursor IDE.

## 🚀 Quick Start

1. **Open in Cursor IDE**
2. **Open Composer Chat** (Cmd/Ctrl + I)
3. **Type**: `@orchestrator Build a social media app with React Native and Node.js`
4. **Watch the agents work together!**

## 🤖 Available Agents

- **@orchestrator** - Master coordinator
- **@prd-writer** - Product Requirements Document
- **@project-manager** - Task breakdown and planning
- **@researcher** - Technology research
- **@architect** - System design
- **@backend-developer** - Server-side implementation
- **@frontend-developer** - UI implementation
- **@code-refactorer** - Code optimization
- **@security-auditor** - Security review
- **@qa-test** - Testing
- **@devops** - Deployment
- **@documentation** - Technical docs

## 🛠️ Technology Support

**Frontend**: React, Vue, Angular, Svelte, React Native, Flutter, Ionic, Xamarin, Swift, Kotlin, Electron, Tauri

**Backend**: Node.js, Python, Java, C#, Go, Rust, PHP

**Mobile**: React Native, Flutter, Ionic, Xamarin, Swift (iOS), Kotlin (Android)

**Databases**: PostgreSQL, MySQL, MongoDB, SQLite, Redis

**Deployment**: Docker, Kubernetes, AWS, Azure, GCP, Vercel, Netlify

Edit any agent by modifying the corresponding JSON file in `.cursor/agents/`. Each agent can be customized for specific needs or technology stacks.
